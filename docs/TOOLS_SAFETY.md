# How safe are the tools you run on your own computer?

Checked on 3 October 2026. This page is for you and for whoever helps you with the site.

## Why it matters

Many of the tools on this site run on your own computer. They read things that other people wrote: a photo someone sent, a spreadsheet a friend filled in, a map saved from another website, a translation, an address you pasted. If one of those carries something nasty, the tool must not run it, must not copy it into a place where it can run later, and must not put a stranger's words into your terminal window.

So each tool was tried with hostile input, on a temporary copy of the site. Your own files were not touched. The tries are now automatic checks. After you change a tool, run them:

    python3 tools/test_safety.py
    node tests/run-all.mjs tools-safety owner-input

The first needs Python 3.8 or newer and takes about 30 seconds. The second also looks at the real pages in a browser. Neither needs the internet.

## What was tried, found and fixed

|---|---|---|---|

| `tools/serve.py` | A request for a path with control characters in it | They were printed in your terminal window, where they can change the window title or hide words | Control characters are shown as `?` |
| `tools/serve.py` | A key or password file left in the folder (`.pem`, `.key`, `id_rsa`, `.env`, `.db`) | It was shown like any other file | Those names are never shown |
| `tools/serve.py` | `..` in every spelling (`%2e%2e`, `..%2f`, `\..\`, double encoding, a null byte), a link that leads outside the folder, a folder listing, the `.git` folder, a request that is not GET or HEAD | All refused | Nothing (already safe). A header now also stops other websites from loading its files into their own pages |
| `tools/review_sheet.py export` | A translation that starts with `=`, `+`, `-`, `@`, a tab or a line break (a spreadsheet formula such as `=HYPERLINK(...)`), and markup or a script in a translation | Each cell is kept as text with a space in front, and the page of the sheet shows markup as plain letters | Nothing (already safe) |
| `tools/review_sheet.py import` | A correction that adds `<script>`, `<img onerror>`, a capital-letter mark, a handler or a style on a mark, `javascript:`, a removed or added `{placeholder}` | All refused with a plain reason | Nothing (already safe) |

## What was found on the page itself

What you type into `js/content.js` reaches visitors. Hostile notice text, reviews, a week note, closures, a photo, a community credit, hours, a Mailchimp address and an analytics address were typed in and the real page was looked at (`tests/owner-input.test.mjs`).

- Found: a review with an address that starts with `javascript:` or `data:` became a link. Clicking it would run the code. Fixed: only an `https://` address becomes a link. Otherwise the source shows as plain text.
- Found: an analytics script address that did not start with `https://` was still put in the page. Fixed: it is not loaded, and the Site check box says so.
- Found: `week.feed` could be any address. Fixed: only `https://` or a file of this website is used, and the Site check box says so.
- Already safe: words in the notice bar, a review, a note or a photo are shown as plain text, never as marks. No script ran and no pop-up opened. The Mailchimp form needs an `https://` address on `list-manage.com` and stays hidden otherwise. A photo of another website in the community strip is refused. Every link that opens a new tab says `noopener`.

## What is left, and why

- **A picture is opened by Pillow.** It reads JPEG, PNG, WebP and HEIC. A bug inside Pillow itself is not something this site can stop. Keep Pillow up to date (`pip install --upgrade pillow`). The tool refuses files over 60 MB or 100 million pixels before it decodes them, and it never opens a format other than a picture.
- **`tools/serve.py` is not password protected.** It binds only to your own computer and answers only to the names above, but anyone else who is logged in to the same computer can reach it. Close its window when you leave a shared computer.
- **`launch_check.py` looks a name up before it connects.** A site that changes its answer between those two steps is not covered. It only sends plain GET requests and reads at most 30 MB.
- **Wording, not safety, is for a native speaker.** The rules refuse markup, code, lost placeholders, changed numbers and names. A harmless but wrong word passes. That is what the yearly check by a native speaker is for.
- **A QR sign can point anywhere on `https://`.** The tool refuses unsafe shapes but cannot know which sites you trust. Look at the address printed under each code before you print the signs, because a printed sign cannot be taken back.
- **A picture address in the gallery list may be on another website.** Only `add_photo.py` writes that list, and it writes local files. If you type an address of another website there yourself, that website sees the visitor's address.
- **Windows.** Making a link there needs special rights, so the link checks were run on Linux. The code uses the same checks on every system.
- **The little test server in `tests/lib.mjs`** has no Host check. It runs for a few minutes during a test, on your own computer only.
