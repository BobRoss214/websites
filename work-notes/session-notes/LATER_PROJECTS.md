# GitHub projects to remember for later (when a pretend feature becomes real)

Looked up in November. Check each licence again on its own page before using it.

| Project | For | Licence, as found | Note |
| --- | --- | --- | --- |
| `lucaong/minisearch` | the search box | MIT | Only if the site's own small search is not good enough. Copy it in with its licence; load it only when the search opens. |
| `krisk/Fuse` | the search box | Apache-2.0 | Forgives typos. Second choice. |
| `pages-cms/pages-cms` | the owner page, "Updates from the farm" | open source, free | Edits the site's files in a form, on top of GitHub. Simplest fit. |
| `decaporg/decap-cms` | the same | MIT (from memory) | Older; reports differ on how active it is. |
| `tastyigniter/TastyIgniter` | real pizza orders | MIT (from memory) | A whole ordering system. Only if the farm leaves Square. |
| `mighty840/kitchenasty` | real kitchen screen | MIT | New in 2026: read it for ideas, do not depend on it yet. |
| `medusajs/medusa` | a real Store basket | MIT (from memory) | Heavy. Square's own shop may suit a small farm better. |
| `alextselegidis/easyappointments` | tree and party bookings | GPL-3.0 (from memory) | The farm uses Bookeo; keeping Bookeo is probably wiser. |
| `umami-software/umami` | real visit numbers | MIT (from memory) | `js/analytics.js` is already ready for it. |
| US weather service API (`api.weather.gov`) | weather on the site | free for any use | No key. |

Not recommended: `open-meteo/open-meteo` (free only for non-business sites), `calcom/cal.com` (its free version changed in 2026 and is for personal use).
Not needed (the site has its own, lighter): a chart library, Workbox, confetti, PhotoSwipe, driver.js, Leaflet.
