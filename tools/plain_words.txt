# [jargon]  words the owner should not have to meet. "word = what to write instead". A word here may not appear in an owner-facing section
#           (tests/plain-lint.test.mjs fails on it). Matching ignores capitals and also matches the plural and "-ed" / "-ing" forms.
#           Words inside `backticks` or "double quotes" are never checked: a file name, a command or a quoted setting is not "jargon", it is the
#           thing itself, and a word on a screen label or in a quotation is somebody else's.
# [known]   capital-letter abbreviations a farm owner already knows (no explanation needed).
# [terms]   words that are fine once they are explained. The tool tells you when one is used before its explanation (it looks at the sentence
#           that uses it and the one after). "word = how to explain it".
# [allow]   a place where a jargon word has to stay. "file name :: word" (the file name is the file's own name, for example QUESTIONS_FOR_THE_FARM.md).
# [hold]    a sentence that is held back from the two limits (sentence length, [jargon]) because it cannot be rewritten alone. "path :: the first words
#           of the sentence, as the tool prints them in its list" (code in `backticks` shows as a section sign). The tool fails when an entry matches
#           no sentence, so an entry cannot outlive the sentence it protects.
